Other rules in the simulation
    Synthetic mode: every day is an independent win (+risk × RR) or loss (−risk) drawn with the chosen win rate. Real NQ data mode: every trader trades the same real sessions, entering at the 10:00 ET open in a random direction, with the bracket replayed against actual 1-minute highs and lows (targets rounded to whole points; when stop and target are both hit in the same minute the order is unknowable and settled by a coin flip; open trades close at 16:00). Costs are deducted in both modes, and the same random draws are reused for every setting, so moving a slider changes only that input. Educational tool only, not financial advice. Rules are a generic model of common futures prop firm terms and will differ from any specific firm.
